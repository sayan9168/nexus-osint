# Investigation Templates

## Domain Triage
1. Create a case and record authorization.
2. Add the domain as a target.
3. Run DNS/RDAP collection.
4. Review A/AAAA/MX/NS/TXT/CNAME/CAA and registration events.
5. Preserve evidence hashes and source attribution.
6. Export Markdown/HTML/JSON.

## Infrastructure Review
1. Add an authorized public IP or URL.
2. Run bounded public collection.
3. Review reverse DNS, HTTP security headers and TLS metadata.
4. Link observed entities and relationships.
5. Review timeline and confidence score.
