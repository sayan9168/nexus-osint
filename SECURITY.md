# Security & Responsible Use

## Scope

NEXUS-OSINT is intended for lawful OSINT, defensive security research, threat intelligence, and investigations where the operator has permission to examine the target.

## Safety principles

- Declare authorization before active collection.
- Prefer public, attributable sources and respect provider terms and rate limits.
- Do not use the project to obtain credentials, bypass authentication, access private accounts, or exploit systems.
- Do not perform bulk profiling, harassment, doxxing, or collection of sensitive personal information.
- Keep evidence tied to a source, timestamp, target, and confidence value.
- Treat automated results as leads, not proof.

## Reporting a vulnerability

Please open a private security report through the repository's supported GitHub security reporting flow when available. Do not publish credentials, private data, or a working exploit in a public issue.
